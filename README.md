**Features**

- PDF Compression
- Image Compression
- OCR Text Extraction
- PDF Merge & Split
- PDF to Image Conversion
- Document Conversion
- Conversion History
- Dark Mode

**Technology**

`Python · Flask · HTML · CSS · JavaScript · Docker · Tesseract OCR`

### TERMINAL_VOTE

A lightweight browser-based secret voting engine designed for social games.

**Features**

- Private voting screens
- Duplicate-vote prevention
- Dynamic tie handling
- Two-target voting
- Neo-Brutalist interface
- CRT scanline effects
- No backend or database required

**Technology**

`HTML · CSS · JavaScript · Tailwind CSS`
